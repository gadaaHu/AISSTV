Five layers, edge-first, one database.

Technology stack

Every choice made for reliability and clarity.

Edge / Vision

  • Python 3.11
  • Ultralytics YOLOv8
  • InsightFace / ArcFace
  • ByteTrack
  • OpenCV

Backend

  • FastAPI
  • SQLAlchemy 2.0 (async)
  • asyncpg
  • Alembic
  • Pydantic v2

Data

  • PostgreSQL 16
  • Structured indexes
  • JSONB metadata
  • Time-series ready
  • Migration history

Frontend

  • React 18
  • TypeScript
  • Vite
  • Tailwind CSS
  • React Router v6

Mobile

  • Flutter 3.24
  • Riverpod
  • GoRouter
  • Dio
  • Freezed

Deploy

  • Docker Compose
  • Mosquitto MQTT
  • Caddy TLS
  • systemd
  • GitHub Actions
